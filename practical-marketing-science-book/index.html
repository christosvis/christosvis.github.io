Preface

This book is for people whose job is to answer a deceptively simple question: what did our marketing actually do?

You might sit in a growth team, an analytics team, an agency or a consultancy. You probably already know how to write SQL, fit a regression and read a confidence interval. What tends to be missing is not technique but judgment: which method fits which question, what each method can and cannot tell you, and how to turn a model output into a budget decision someone will act on. That is the gap this book tries to close.

How this book is organized

The book is organized around the decisions a measurement team supports, not around techniques. Most chapters follow the same shape:

  1. The decision the chapter supports, stated up front.
  2. The method, explained just far enough to use it correctly.
  3. A worked example on simulated data, so you can see the method recover (or fail to recover) a known truth.
  4. Pitfalls: the ways the method goes wrong in practice and how to spot them.
  5. A checklist to run before you trust a result.
  6. Further reading, an annotated selection from the resource library in Appendix A.

Simulated data is a deliberate choice. With real data you never know the true answer, so you cannot tell whether a method worked. With simulated data you set the truth yourself and then check what the method recovers. Every example in the book is reproducible from the code shown.

Code and tools

Examples are in Python. Parts I and II use only numpy, pandas, scipy, statsmodels and matplotlib, so that they run anywhere. Part III adds PyMC for Bayesian marketing mix models; those models are fitted once by fit_models.py (a few minutes on a laptop) and the chapters load the saved results. Where R has the better tool (GeoLift, Robyn, CausalImpact’s original implementation), the text points to it.

The book itself is built with bookdown.

A note on sources

The further-reading sections draw on a curated library of public resources: package documentation, blog posts, courses and open-source code from the marketing science community. The text of this book is original; the resources are pointers for going deeper. Links rot, so where a resource has moved, search for its title.
